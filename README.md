## Why Linear Algebra Is Useful for Machine Learning

Linear algebra is the language of machine learning. In this coursework, students can see that:

- **Data is represented as vectors and matrices** (for example, each image is a numeric matrix).
- **Models learn weights** using vector and matrix operations.
- **Dimensionality reduction (like SVD/PCA)** compresses data while preserving important patterns.
- **Image classification** depends on matrix transformations and distance/similarity calculations.

Understanding these ideas helps students move from using ML tools to understanding how ML models work internally.
